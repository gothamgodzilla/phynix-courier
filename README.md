# Phynix Courier

Lime green autonomous courier service by **Matryxx LLC** (Sheridan, Wyoming).

## Concept
- Matches the **closest vehicle** between Tesla Cybercab (Austin live fleet) and Waymo (Austin + Los Angeles).
- Documents and small parcels **≤ 10 lb only**. People are not cargo.
- ETA-first multi-objective dispatch with predictive graph neural rebalancing simulation.
- **Phoenix Desktop Assistant**: Clippy reborn 2026 — local-first LLM personalization, watches clicks & browser movements (simulated), recursive memory layers (episodic → semantic → procedural), phoenix / bird-of-paradise personality with mecha-brain accents.

## Style
Minimalist clean lines, embossed buttons, lime green (#32CD32 / #39FF14).

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub then connect to Vercel, or use Vercel CLI / Open Hands path.

Human gate remains on domain, deploy, email, and privacy scope.

## Features in prototype
- City selector (Austin / LA)
- Closest-vehicle matching simulation
- Weight guardrail
- Gnomies item-drop desk
- Phoenix chat with localStorage memory
- Tesla Blueprint + Hologram Prism section

Built with Next.js 16 + Tailwind. Ready for testing.
